## Gaps in PE confirmed by this pass (each verified by grep or line read)
1. claim-gate.mjs:90 drops tool_result events, so "tests pass" is checked for command presence, never for result.
2. No claim family for build/typecheck, implemented-symbol, dependency, pushed/deployed/live, "ready to merge".
3. Secret rules: 7 provider shapes (diff.mjs:106-116), no entropy.
4. No commit header/shape rules (commitlint class).
5. No user-defined diff rules.
6. No baseline snapshot of the session start; fix claims cannot be proved.
