# 通俗用语表（简体中文）

和非技术人员交流时用右边一列。缺少的词只解释一次，一句话说清，然后用对方的说法继续。

| term | say instead |
|---|---|
| idempotent | 做两次和做一次的结果一样 |
| backfill | 把旧记录补成和新记录一样的样子 |
| cache invalidation | 让大家不再看到旧的副本 |
| race condition | 两件事同一时刻发生，互相踩了脚 |
| migration | 在数据使用中，小心地改变它的存放方式 |
| feature flag | 一个开关，让新功能先对一部分人打开 |
| p95 latency | 每二十个请求里最慢的那个要花多久 |
| retry with backoff | 再试一次，每次多等一会儿 |
| queue | 一条排队的线，忙的时候也不会丢东西 |
| webhook | 事情一发生，对方系统就来通知我们 |
| rate limit | 一个调用方多久能问一次的上限 |
| rollback | 把上一个版本放回去 |
| regression | 原来能用的东西坏了 |
| tech debt | 走过的一条捷径，修好之前每周都在浪费时间 |
| observability | 事后能看到系统做了什么 |

依据：简体中文没有官方的通俗语言指南，本表以短句、常用词、一句一个意思为准，全部文字为
本仓库自行撰写。
