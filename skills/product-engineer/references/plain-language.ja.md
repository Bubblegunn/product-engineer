# やさしい言葉の表（日本語）

技術者でない人と話すときは右の列を使う。足りない言葉は一度だけ一文で説明し、あとは相手の
言葉で続ける。

| term | say instead |
|---|---|
| idempotent | 二回やっても一回やったのと同じ結果になる |
| backfill | 古い記録を新しい記録と同じ形にそろえること |
| cache invalidation | 古いコピーが見え続けないようにすること |
| race condition | 二つのことが同時に起きてぶつかること |
| migration | 使っている最中に、データの保存のしかたを慎重に変えること |
| feature flag | 新しい動きを一部の人にだけ先に出せるスイッチ |
| p95 latency | 二十回に一回の遅い処理にかかる時間 |
| retry with backoff | 少しずつ待ち時間を長くしながらやり直すこと |
| queue | 混んでいても何も失わないための順番待ちの列 |
| webhook | 何かが起きた瞬間に相手のシステムがこちらに知らせること |
| rate limit | 一人が頼める回数の上限 |
| rollback | 前の版に戻すこと |
| regression | 前は動いていたものが壊れること |
| tech debt | 直すまで毎週時間を奪う近道 |
| observability | あとから、システムが何をしたか見られること |

よりどころ: 出入国在留管理庁と文化庁が示す「やさしい日本語」のガイドライン。一文を短く、
一つの文に一つの内容、漢語より和語を選ぶ、という方針に沿っている。文言はここで書き下ろした。
