# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, argue about the work and not the person, and
accept that a maintainer may close a discussion that has stopped being about the work.

Report unacceptable behaviour to the maintainer through a GitHub issue marked "conduct"
or by email at the address on the maintainer's GitHub profile. Reports are handled
privately and promptly.
