Changes since v1.4.0 (commit bd97d27 to d85083e)

The bookings list now shows 50 bookings at a time, so a long list no longer has to be drawn all at once.
Guests whose booking was cancelled no longer get the day-before reminder; only guests with a booking that is still on get one.
Exported booking files can no longer run commands when you open them in a spreadsheet program.

Not in this release:
- Cancelling several bookings at once from the bookings page: it was added and then taken back out, so it is not available.
