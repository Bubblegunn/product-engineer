# Release Notes — Version 1.4.1

## Fixes

- **Cancelled bookings no longer get reminders.** The day-before reminder was being sent for bookings that had been cancelled. Guests who cancel will no longer receive it.
- **Safer CSV exports.** Exported booking data is now protected so that spreadsheet programs (Excel, Google Sheets, etc.) won't run formulas hidden in guest-entered text. Your exports open as plain data.

## Improvements

- **Faster bookings list.** The bookings list now shows 50 bookings per page instead of loading everything at once, so it opens faster, especially if you have a lot of bookings.
