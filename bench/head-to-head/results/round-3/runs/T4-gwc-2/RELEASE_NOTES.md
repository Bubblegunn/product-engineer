# Release Notes — since v1.4.0

## Improvements
- **Faster bookings list:** The bookings list now shows 50 bookings per page, so it loads quicker if you have a lot of reservations.

## Fixes
- **Day-before reminders:** Guests who cancelled their booking no longer receive the day-before reminder.
- **Safer CSV exports:** Exported CSV files are now protected so that spreadsheet apps (Excel, Google Sheets, etc.) won't run formulas hidden in booking data, such as a guest name.
