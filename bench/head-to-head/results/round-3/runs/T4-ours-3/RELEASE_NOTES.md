Changes since v1.4.0 (commit bd97d27 to d85083e)

You can now page through your bookings 50 at a time, so a long list is shown in manageable pieces instead of all at once.
Guests with a cancelled booking no longer get the day-before reminder; only bookings that are still on are reminded.
Exported booking spreadsheets (CSV files, which open in Excel or similar) can no longer run commands hidden in a booking's text when a colleague opens them.

Not in this release:
- Bulk cancel button on the bookings page: it was added and then taken back out within this range, so it is not available.
