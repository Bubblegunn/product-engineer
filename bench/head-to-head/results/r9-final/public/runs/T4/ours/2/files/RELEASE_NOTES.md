Changes since v1.4.0

The bookings list now shows 50 bookings at a time, so a long list is split into pages instead of arriving all at once.
Guests whose booking was cancelled no longer get a day-before reminder; only bookings that are still on are reminded.
Spreadsheet files exported from your bookings can no longer run commands when you open them in a spreadsheet program, because any entry that starts like a formula is now saved as plain text.
Stay totals (nightly rate times number of nights) are now rounded to two decimal places, so a total never shows stray fractions of a cent.

Not in this release:
- Bulk cancel button on the bookings page: it was added and then withdrawn, so you still cancel bookings one at a time.
