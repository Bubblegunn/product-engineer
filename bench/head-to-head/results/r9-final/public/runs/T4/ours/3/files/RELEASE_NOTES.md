Changes since v1.4.0

The bookings list now shows 50 bookings at a time, so a long list is split into pages instead of arriving all at once.
Guests whose booking was cancelled no longer get the day-before reminder; only bookings that are still on will.
Exported booking spreadsheets can no longer run commands when you open them. A guest name that starts with a symbol such as "=" is now shown as plain text, which protects your computer and your data.
Stay totals are now rounded to two decimal places (whole cents), so a price never shows a fraction of a cent.

Not in this release:
- Cancelling several bookings in one step: it was started and then taken back before release, so the bookings page does not have it yet.
