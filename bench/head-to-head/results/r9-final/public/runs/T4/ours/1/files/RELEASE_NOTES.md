Changes since v1.4.0

The bookings list now shows 50 bookings at a time, so a long list is split into pages instead of arriving as one block.
Cancelled bookings no longer get a day-before reminder; only bookings that are still on will.
Exported spreadsheet files can no longer run commands when you or a colleague open them, because the export now treats booking text as plain text.
The total for a stay is now rounded to two decimal places (cents), so a nightly rate times the number of nights never shows a stray fraction of a cent.

Not in this release:
- Bulk cancel button on the bookings page: it was added and then taken out again, so you cannot cancel several bookings at once yet.
