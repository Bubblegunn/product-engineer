# Release Notes

## What's new since v1.4.0

### Fixes
- **Safer CSV exports.** Exported booking files can no longer contain content that a spreadsheet program (Excel, Google Sheets) might mistakenly run as a formula when you open them.
- **Day-before reminders skip cancelled bookings.** Guests who cancelled will no longer receive a reminder about a stay they aren't coming to.

### Improvements
- **Faster bookings list.** The bookings page now shows 50 bookings per page, so it loads faster, especially if you have a lot of reservations.
