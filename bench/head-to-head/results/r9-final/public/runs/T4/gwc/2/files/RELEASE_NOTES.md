# Release Notes: 1.4.1

## Improvements
- **Faster bookings list.** The bookings page now shows 50 bookings per page, so it loads quicker if you have a lot of reservations.

## Fixes
- **Cancelled bookings no longer get reminders.** Guests who cancelled will no longer receive the day-before reminder email.
- **Safer CSV exports.** Exported booking files can no longer run formulas when opened in Excel or Google Sheets, which protects you from malicious content in guest-entered fields.
