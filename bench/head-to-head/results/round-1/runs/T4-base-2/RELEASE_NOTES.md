# Release Notes – Version 1.4.1

## Improvements
- **Faster bookings list:** The bookings page now shows 50 bookings at a time instead of loading everything at once, so it opens faster, especially if you have a lot of bookings.

## Fixes
- **Day-before reminders no longer go out for cancelled bookings:** Guests who cancelled will no longer receive a reminder about a stay they cancelled.
- **Safer CSV exports:** Exported booking files are now protected so that spreadsheet programs such as Excel won't run any formulas hidden in guest-entered text (for example, in a name or notes field).
