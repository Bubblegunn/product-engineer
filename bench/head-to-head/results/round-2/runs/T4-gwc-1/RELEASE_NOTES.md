# Release Notes

## Version 1.4.1

### Fixes
- **No more reminders for cancelled bookings.** The day-before reminder is no longer sent to guests whose booking has been cancelled.
- **Safer CSV exports.** Exported booking files can no longer contain text that a spreadsheet program (Excel, Google Sheets, etc.) would run as a formula, so opening an export is safe.

### Improvements
- **Faster bookings list.** The bookings list now shows 50 bookings per page, so it loads quicker if you have a lot of reservations.
