# Release notes: version 1.4.1

## What changed for you

### Cancelled bookings no longer get a reminder email
Before this update, guests whose booking was cancelled could still get the "see you tomorrow" email the day before their arrival date. This no longer happens. Only active bookings get a reminder.

### Your bookings list loads faster
The bookings page now shows 50 bookings at a time instead of all of them at once. If you have a lot of bookings, the page opens more quickly.

### Safer CSV exports
When you export bookings to CSV and open the file in a spreadsheet app such as Excel, text that looks like a formula (for example, a guest name that starts with `=`) is no longer run by the spreadsheet. Your exported data is the same, but it is now safe to open.

## Nothing to do
You don't need to change any settings. These changes apply automatically.
