Changes since v1.4.0 (commit 23e32d1 to e861353)

You can now export your bookings as a JSON file (a plain-text format that spreadsheets and other software can read), so you can hand your booking list to other tools as well as to CSV. It includes the booking number, guest name and check-in date; nothing else is exported.
Stay totals are now rounded to two decimals, so a total such as three nights at 0.10 shows 0.30 instead of a long string of digits.
