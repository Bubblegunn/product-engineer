Changes since v1.4.0 (commit 1ee2019 to dc71afd)

You can now search your bookings by guest name, so finding a reservation no longer means scrolling the whole list. Capital letters don't matter: "smith" finds "Smith".
Exported booking spreadsheets can no longer run unwanted instructions when you or a colleague open them, because guest names that start like a spreadsheet formula are now treated as plain text.
Guest names that contain a comma now stay in one column in the exported spreadsheet, instead of splitting across two.
