# StayHub 1.5.0 Release Notes

What's new since 1.4.0.

## Improvements

- **Bookings list is now paginated.** The bookings list shows 50 bookings per page instead of loading everything at once, so it stays quick as your booking history grows.
- **Faster CSV export.** Exporting your bookings to CSV is now more efficient, which helps most if you have a large number of bookings.

## Fixes

- **No more reminders for cancelled bookings.** Guests who cancelled will no longer receive a check-in reminder email.

## Good to know

- Reminder emails are sent the day before check-in. This is now documented in the README.
