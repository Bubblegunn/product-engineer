Changes since v1.4.0 (commit 8353ee3 to 70e79e5)

Guests can now ask for a late checkout, and the request is held until 14:00 unless a different time is given, so a guest no longer needs to ask at the desk.
Arrival reminders are no longer sent for cancelled bookings; only bookings that are still on your books get one.
Your nightly rate in price quotes is now 135 euros instead of 120 euros, so a quote for a stay is the number of nights times 135 euros. Check that this is the rate you want.
Guest lists you download as a spreadsheet file can no longer run commands when you open them, even if a guest typed a name that starts with a formula symbol.

Not in this release:
- Late checkout was added, taken out, and put back during this period; it is included here. Nothing else in the product asks for it yet, so for now it is not shown on any screen.
