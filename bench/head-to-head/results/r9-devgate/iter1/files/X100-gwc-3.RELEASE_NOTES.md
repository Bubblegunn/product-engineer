# Release Notes

## Changes since v1.4.0 (now at v1.6.0)

### New
- **Export bookings as JSON.** Besides CSV, you can now export your bookings as JSON. Each entry includes the booking ID, guest name and check-in date, the same details as the CSV export.

### Fixed
- **Stay totals are now rounded to the cent.** Totals (nights × nightly rate) are rounded to 2 decimal places, so you won't see stray fractions of a cent in quotes.
