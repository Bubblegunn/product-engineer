Changes since v1.4.0 (commit 6314805 to e861353)

You can now export your bookings as a JSON file (a plain-text format that spreadsheets and other software can read), so you can move guest names and check-in dates into other tools. The file holds only the booking number, guest name and check-in date.
Stay totals are now rounded to two decimals, so a total such as three nights at 0.10 shows 0.30 instead of a long string of digits.
