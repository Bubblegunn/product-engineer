Changes since v1.4.0 (commit 8353ee3 to 70e79e5)

Guests can now ask for a late checkout, so you can offer them extra time in the room; a request is held until 14:00 by default.
Cancelled bookings no longer trigger an arrival reminder; only bookings that are still on your books do.
Spreadsheet files you export can no longer run hidden commands when you or a colleague open them, because guest names that look like spreadsheet formulas are now treated as plain text.
The price of a night is now 135 euros instead of 120 euros, so new quotes use the updated rate.
