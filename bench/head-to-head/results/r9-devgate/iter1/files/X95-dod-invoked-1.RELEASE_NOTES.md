# StayHub 1.5.0 — Release Notes

What's new since 1.4.0.

## Improvements

- **Faster bookings list.** The bookings list now loads in pages of 50, so it stays quick even if you have a lot of reservations.
- **Faster CSV export.** Exporting your bookings to CSV is now more efficient, which helps most when you export large lists.

## Fixes

- **No more reminders for cancelled bookings.** Guests who cancel will no longer receive a check-in reminder email.

## Documentation

- The README now explains that reminders are sent by email the day before check-in.
