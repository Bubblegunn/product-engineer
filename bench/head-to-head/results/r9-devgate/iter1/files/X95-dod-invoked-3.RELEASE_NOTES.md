# StayHub release notes

## What's new since v1.4.0 (now version 1.5.0)

### Fixed
- **No more reminders for cancelled bookings.** Guests who cancelled no longer get a check-in reminder email.

### Improved
- **Bookings list is now paginated.** The list shows 50 bookings at a time, so it stays quick to open when you have a lot of bookings.
- **Faster CSV export.** Exporting your bookings to CSV is more efficient, which helps most if you have a large number of bookings.

### Good to know
- Reminders are sent by email the day before check-in. This is now described in the documentation.
