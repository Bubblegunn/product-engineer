# Release Notes

Changes since v1.4.0, now available in v1.6.0.

## New

- **Export bookings as JSON.** Besides CSV, you can now export your bookings as JSON. Each entry includes the booking ID, the guest name and the check-in date. This makes it easier to move your booking data into other tools.

## Fixed

- **Stay totals are now rounded to the cent.** Totals for a stay (nights × nightly rate) are rounded to 2 decimal places, so you no longer see totals with stray fractions of a cent.
