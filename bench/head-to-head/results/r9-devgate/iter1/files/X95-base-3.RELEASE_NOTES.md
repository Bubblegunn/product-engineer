# StayHub 1.5.0

## Fixes

- **No more reminders for cancelled bookings.** Guests who cancelled will no longer receive a check-in reminder email.

## Improvements

- **Faster bookings list.** The bookings list now shows 50 bookings per page instead of loading everything at once. In our test with 10,000 bookings, the list loaded in about 38 ms, down from about 412 ms. Results will vary with your hardware and data.

## Documentation

- The README now explains that reminders are sent by email the day before check-in.
