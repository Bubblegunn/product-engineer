# StayHub Release Notes

Changes since v1.4.0 (current version: 1.6.0).

## New

- **JSON export.** Besides CSV, you can now export your bookings as JSON. Each entry includes the booking ID, guest name and check-in date. This makes it easier to move your booking data into other tools.

## Fixed

- **Stay totals are now rounded to 2 decimals.** The total for a stay (nights × nightly rate) is now rounded to the cent, so you won't see totals with stray extra decimals.

## Improvements

- Updated the library behind CSV export to a newer version.
