Changes since v1.4.0 (commit 8353ee3 to 70e79e5)

A guest can now ask for a late checkout, so that you can offer extra time on the day they leave. The request is held until 14:00 unless you choose another time.
Cancelled bookings no longer get an arrival reminder, so that only guests who are still coming are reminded.
Spreadsheet files exported from your bookings are now safe to open: a guest name that starts with a symbol such as an equals sign is shown as plain text instead of being run as a calculation by your spreadsheet program.
The nightly rate used to price a stay is now 135 EUR instead of 120 EUR, so quotes for new stays are higher; check this matches the rate you want to charge.
