Changes since v1.4.0

You can now export your bookings as a JSON file (a plain-text format that other software, such as spreadsheets and accounting tools, can read), so moving your guest list, check-in dates and booking numbers into other tools no longer means retyping them.
Stay totals are now rounded to whole cents, so a nightly rate multiplied by the number of nights no longer produces totals with stray extra decimals.
If you run the software on your own computer or server, it now needs Node version 20 or newer (Node is the program that runs it; the previous minimum was 18), so update it before installing this release.
