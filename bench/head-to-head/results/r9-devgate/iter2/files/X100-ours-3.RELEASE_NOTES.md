Changes since v1.4.0

You can now export your bookings as a JSON file (a plain-text format that other software can read), so moving your booking list into other tools no longer means retyping it. Each entry has the booking number, the guest name and the check-in date.
Stay totals are now rounded to two decimal places (whole cents), so a nightly rate times the number of nights no longer shows a long trail of digits.
If you run the software on your own server, it now needs Node version 20 or newer (Node is the program that runs it; version 18 is no longer supported), so update Node before installing this release.
