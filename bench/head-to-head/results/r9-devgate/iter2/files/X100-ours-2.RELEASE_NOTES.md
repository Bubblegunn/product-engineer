Changes since v1.4.0

You can now export your bookings as a JSON file (a plain-text format that other software, such as accounting or reporting tools, can read), so moving your booking list into those tools no longer means retyping it.
Stay totals are now rounded to 2 decimals (whole cents), so a price like a nightly rate times a number of nights no longer shows a long string of digits.
If you run the software on your own server, you now need Node 20 or newer (the engine that runs the software; version 18 is no longer supported), so update it before installing this release.
