Changes since v1.4.0

Guests can now ask for a late checkout, so you can offer a later departure (until 14:00 unless you set another time) without handling it by hand.
Stay quotes now use a nightly rate of €135 instead of €120, so a quote for a stay is €15 higher for each night.
Cancelled bookings no longer trigger an arrival reminder; only bookings that are still on will.
Exported booking lists (spreadsheet files with one booking per line) can no longer run commands when you open them in a spreadsheet program, because guest names that start with a formula symbol are now stored as plain text.
