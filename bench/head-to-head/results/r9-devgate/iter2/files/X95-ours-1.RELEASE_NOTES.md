Changes since v1.4.0

You can now page through your bookings 50 at a time, so a long bookings list no longer has to be built all at once (measured on a list of 10,000 bookings, median of 5 runs on a laptop: 412 ms before, 38 ms after).
Guests with a cancelled booking no longer get a reminder; only bookings that are still on will.

Not in this release:
- Group bookings: this was added and then taken back out within this range, so it is not available.
