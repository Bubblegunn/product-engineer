Changes since v1.4.0

Guests can now ask for a late checkout, so you can offer a later departure; a request is held until 14:00 unless another time is set.
Booking quotes now use a nightly rate of €135 instead of €120, so a 3-night stay is quoted at €405 instead of €360.
Cancelled bookings no longer trigger an arrival reminder; only bookings that are still on will.
Exported booking spreadsheets can no longer run commands hidden in a guest's name when you open them in a spreadsheet program.
