Changes since v1.4.0

You can now search your bookings by guest name, so you can find a reservation without scrolling through the whole list. Part of a name is enough, and capital letters don't matter.
Exported booking files (CSV, a spreadsheet-friendly format) can no longer run unwanted instructions when you open them in a spreadsheet program, so guest names typed by someone else are safe to open.
Guest names that contain a comma, such as "Silva, Ana", now stay in a single column in exported booking files instead of splitting across two.
The bookings list now shows 25 bookings per page instead of 50, so each page is shorter; you will see more pages for the same bookings.
