Changes since v1.4.0

You can now record a late checkout request on a booking, with a default checkout time of 14:00, so a guest who asks to stay longer is written down instead of remembered.
Cancelled bookings no longer send an arrival reminder; only bookings that are still on will.
Booking lists exported as a spreadsheet file (CSV, a plain table that Excel and similar programs open) can no longer run formulas hidden in a guest's name when you open them, which protects the computer of whoever opens the file.
The price quoted for a stay is now based on a nightly rate of 135 euros, up from 120 euros, so every quote is 15 euros per night higher than before.
